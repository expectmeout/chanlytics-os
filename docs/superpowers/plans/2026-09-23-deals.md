# Deals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `docs/decisions/0004-deals-record.md`: a `deals` record a person writes and every surface reads once, so a workspace that sells an engagement after a consultation can see a proposal out, a client, a pass and an ending, and the receptionist treats a client as one.

**Architecture:** One table and one SQL door (00154), the people read recreated to carry the newest open or current deal, a pure contracts module (`deals.ts`) that every page and both receptionists read, one route (`POST contacts/[id]/deal`) that calls the door and records the decision, and small additions at the seams the decision note names: a rail section on the person's page in the consent asks' family, four Journey lists, a hidden column, the thread's chip and menu, Today's leak, Reports' cohort sentence, the who-this-is note both receptionists read, the voice availability door, and Ask. No guard trigger: every move is an event and the row's `version` refuses a stale press.

**Tech Stack:** Postgres (Supabase, RLS, SECURITY DEFINER doors), TypeScript packages (`contracts`, `db`), Next.js route handlers declared with `route()`, the legacy React shell bridged through `window` globals, `node:test` under `tsx`, Playwright nightly.

```sql
-- 00154 · A deal is a record.
--
-- docs/decisions/0004-deals-record.md. One row per engagement a person is
-- deciding on or has taken: a proposal out, a client, passed, ended. Written
-- by a person through deal_record (an Ask card commits through the same
-- route), never by the receptionist, which reads a deal as it reads the
-- calendar. A stage is an owner's assertion, not a fact about time, so there
-- is no guard trigger: every move is allowed, every move is an event, and the
-- row's version refuses a stale press (the leads' Undo rule, 00142). The
-- people read is recreated whole (00138's rule) to carry the newest open or
-- current deal.
--
-- Two statements take ACCESS EXCLUSIVE on tables a live workspace reads (the
-- CHECKs on decisions, the trigger on contacts), so the same lock guard as
-- 00140 and 00142.
set local lock_timeout = '3s';
do $$
begin
  raise notice 'lock_timeout for this migration: %', current_setting('lock_timeout');
  if current_setting('lock_timeout') <> '3s' then
    raise warning 'this file was applied outside a transaction, so SET LOCAL did nothing: run it inside begin/commit, or set lock_timeout yourself before it';
  end if;
end $$;

/* ------------------------------------------------------------- 1. the table -- */

create table if not exists public.deals (
  id             uuid primary key default gen_random_uuid(),
  tenant_id      uuid not null references public.tenants (id) on delete cascade,
  contact_id     uuid not null references public.contacts (id) on delete cascade,
  lead_id        uuid references public.leads (id) on delete set null,
  -- The profile's service by name, as consult_first names one; null when the
  -- profile lists one service or none.
  service        text check (service is null or char_length(service) between 1 and 80),
  stage          text not null check (stage in ('proposed', 'won', 'lost', 'ended')),
  proposed_at    timestamptz not null default now(),
  decided_at     timestamptz,
  ended_at       timestamptz,
  amount_cents   integer check (amount_cents is null or amount_cents >= 0),
  per            text check (per is null or per in ('once', 'month', 'year')),
  currency       text not null default 'USD' check (currency ~ '^[A-Z]{3}$'),
  note           text check (note is null or char_length(note) between 1 and 200),
  -- The consent's shape: {"message_id": ...} for their own message, {"form": "..."} for one signed elsewhere.
  evidence       jsonb,
  -- Who wrote the stage. The product never writes 'receptionist': it does not decide.
  source         text not null default 'person' check (source in ('person', 'payment')),
  version        integer not null default 1,
  created_by     uuid references auth.users (id) on delete set null,
  created_at     timestamptz not null default now(),
  updated_at     timestamptz not null default now()
);

Written by deal_record on a person''s word, an Ask card through the same route, or a payment webhook later (source); never by the receptionist. A stage is an assertion, so no guard: every move is an event and version refuses a stale press. One open engagement (proposed or won) per person per service.';

/* --------------------------------------------------------------- 2. the door -- */

-- The one door. No id: a new engagement, which starts as a proposal. An id
-- and the version the page saw: a move, refused when anyone changed the row
-- since. Acting members only (is_acting_member, 00014). Each stage's event is
-- written here with its kind as a literal, so the kinds lint sees the emitter
-- (tooling/scripts/tests/event-kinds.test.mjs reads the first dotted literal
-- of each insert). The route records the decision (record_deal on subject
-- deal), as the consent route does.
create or replace function public.deal_record(
  p_contact_id   uuid,
  p_stage        text,
  p_deal_id      uuid default null,
  p_version      integer default null,
  p_service      text default null,
  p_when         timestamptz default null,
  p_amount_cents integer default null,
  p_per          text default null,
  p_note         text default null,
  p_evidence     jsonb default null
)
returns jsonb
language plpgsql
security definer
set search_path = public
as $$
declare
  v_user    uuid := auth.uid();
  v_tenant  uuid;
  v_row     public.deals%rowtype;
  v_from    text;
  v_service text := nullif(btrim(coalesce(p_service, '')), '');
  v_note    text := nullif(btrim(coalesce(p_note, '')), '');
  v_when    timestamptz := coalesce(p_when, now());
begin
  if v_user is null then
    raise exception 'Sign in required.' using errcode = '28000';
  end if;
  if p_stage is null or p_stage not in ('proposed', 'won', 'lost', 'ended') then
    return jsonb_build_object('error', 'bad_stage');
  end if;
  if p_per is not null and p_per not in ('once', 'month', 'year') then
    return jsonb_build_object('error', 'bad_per');
  end if;
  if p_amount_cents is not null and p_amount_cents < 0 then
    return jsonb_build_object('error', 'bad_amount');
  end if;
  if v_note is not null and char_length(v_note) > 200 then
    return jsonb_build_object('error', 'note_too_long');
  end if;
  if v_service is not null and char_length(v_service) > 80 then
    return jsonb_build_object('error', 'service_too_long');
  end if;

  select c.tenant_id into v_tenant
    from contacts c
   where c.id = p_contact_id and c.erased_at is null and c.merged_into_contact_id is null;
  if v_tenant is null or not public.is_acting_member(v_tenant) then
    return jsonb_build_object('error', 'not_found');
  end if;

  if p_deal_id is null then
    -- A new engagement starts as a proposal, and only one may be open per service.
    if p_stage <> 'proposed' then
      return jsonb_build_object('error', 'bad_move');
    end if;
    if exists (
      select 1 from deals d
       where d.contact_id = p_contact_id and d.stage in ('proposed', 'won')
         and coalesce(d.service, '') = coalesce(v_service, '')
    ) then
      return jsonb_build_object('error', 'already_open');
    end if;
    insert into deals (tenant_id, contact_id, lead_id, service, stage, proposed_at, amount_cents, per, note, evidence, created_by)
    values (
      v_tenant, p_contact_id,
      (select l.id from leads l where l.contact_id = p_contact_id and l.erased_at is null
        order by l.converted_at desc nulls last limit 1),
      v_service, 'proposed', v_when, p_amount_cents, p_per, v_note, p_evidence, v_user
    )
    returning * into v_row;
    insert into events (tenant_id, kind, category, subject_type, subject_id, data)
    values (v_tenant, 'deal.proposed', 'deal', 'deal', v_row.id,
            jsonb_build_object('deal_id', v_row.id, 'contact_id', p_contact_id, 'stage', 'proposed',
                               'from', null, 'service', v_row.service, 'by', v_user));
    return jsonb_build_object('deal', to_jsonb(v_row), 'from', null);
  end if;

  select * into v_row from deals d
   where d.id = p_deal_id and d.tenant_id = v_tenant and d.contact_id = p_contact_id
   for update;
  if v_row.id is null then
    return jsonb_build_object('error', 'not_found');
  end if;
  if p_version is not null and p_version <> v_row.version then
    return jsonb_build_object('error', 'moved', 'version', v_row.version);
  end if;
  if v_row.stage = 'ended' and p_stage <> 'ended' then
    -- An ended engagement is re-signed as a new row, so tenure and amounts keep their history.
    return jsonb_build_object('error', 'ended');
  end if;
  if p_stage = 'proposed' and v_row.stage <> 'proposed' and exists (
    select 1 from deals d
     where d.contact_id = p_contact_id and d.id <> v_row.id and d.stage in ('proposed', 'won')
       and coalesce(d.service, '') = coalesce(v_row.service, '')
  ) then
    return jsonb_build_object('error', 'already_open');
  end if;

  v_from := v_row.stage;
  update deals d
     set stage        = p_stage,
         proposed_at  = case when p_stage = 'proposed' and v_from <> 'proposed' then v_when else d.proposed_at end,
         decided_at   = case when p_stage in ('won', 'lost') and v_from <> p_stage then v_when
                             when p_stage = 'proposed' then null
                             else d.decided_at end,
         ended_at     = case when p_stage = 'ended' and v_from <> 'ended' then v_when else d.ended_at end,
         amount_cents = coalesce(p_amount_cents, d.amount_cents),
         per          = coalesce(p_per, d.per),
         note         = coalesce(v_note, d.note),
         evidence     = coalesce(p_evidence, d.evidence),
         version      = d.version + 1
   where d.id = v_row.id
  returning * into v_row;

  if v_from = p_stage then
    -- Refreshing a row's details is not a move: no event.
    return jsonb_build_object('deal', to_jsonb(v_row), 'from', v_from);
  end if;
  if p_stage = 'proposed' then
    insert into events (tenant_id, kind, category, subject_type, subject_id, data)
    values (v_tenant, 'deal.proposed', 'deal', 'deal', v_row.id,
            jsonb_build_object('deal_id', v_row.id, 'contact_id', p_contact_id, 'stage', 'proposed',
                               'from', v_from, 'service', v_row.service, 'by', v_user));
  elsif p_stage = 'won' then
    insert into events (tenant_id, kind, category, subject_type, subject_id, data)
    values (v_tenant, 'deal.won', 'deal', 'deal', v_row.id,
            jsonb_build_object('deal_id', v_row.id, 'contact_id', p_contact_id, 'stage', 'won',
                               'from', v_from, 'service', v_row.service, 'by', v_user));
  elsif p_stage = 'lost' then
    insert into events (tenant_id, kind, category, subject_type, subject_id, data)
    values (v_tenant, 'deal.lost', 'deal', 'deal', v_row.id,
            jsonb_build_object('deal_id', v_row.id, 'contact_id', p_contact_id, 'stage', 'lost',
                               'from', v_from, 'service', v_row.service, 'by', v_user));
  else
    insert into events (tenant_id, kind, category, subject_type, subject_id, data)
    values (v_tenant, 'deal.ended', 'deal', 'deal', v_row.id,
            jsonb_build_object('deal_id', v_row.id, 'contact_id', p_contact_id, 'stage', 'ended',
                               'from', v_from, 'service', v_row.service, 'by', v_user));
  end if;
  return jsonb_build_object('deal', to_jsonb(v_row), 'from', v_from);
end $$;

revoke execute on function public.deal_record(uuid, text, uuid, integer, text, timestamptz, integer, text, text, jsonb) from public, anon;
grant execute on function public.deal_record(uuid, text, uuid, integer, text, timestamptz, integer, text, text, jsonb) to authenticated;
comment on function public.deal_record(uuid, text, uuid, integer, text, timestamptz, integer, text, text, jsonb) is
  'Record a deal on a person''s word (0004). No id: a new engagement, which starts proposed; one open engagement per person per service. An id and the version the page saw: a move (any stage to any, except out of ended, which is re-signed as a new row); a stale version answers {error: moved}. Owner or operator. Writes the stage''s event; the route records the decision. Answers {deal, from} or {error}.';

/* ---------------------------------------------------- 3. an erasure keeps no words -- */

-- A person erased keeps no words: the note and the evidence go; the stage,
-- the dates and the amount are the business's own facts and stay, as a
-- lead's counts do (00140).
create or replace function public.deals_erase_on_contact()
returns trigger
language plpgsql
security definer
set search_path = public
as $$
begin
  if NEW.erased_at is not null and OLD.erased_at is null then
    update deals set note = null, evidence = null, version = version + 1 where contact_id = NEW.id;
  end if;
  return null;
end $$;
revoke execute on function public.deals_erase_on_contact() from public, anon, authenticated;
drop trigger if exists contacts_erase_blanks_deals on public.contacts;
create trigger contacts_erase_blanks_deals
  after update of erased_at on public.contacts
  for each row execute function public.deals_erase_on_contact();
comment on function public.deals_erase_on_contact() is
  'When a person is erased, their deals keep no words: the note and the evidence are blanked; stage, dates and amount stay (0004).';
```

```ts
/**
 * A deal is a record (docs/decisions/0004-deals-record.md).
 *
 * One engagement a person is deciding on or has taken: a proposal out, a
 * client, passed, ended. Everything a page or a receptionist says about one
 * is derived here, once: the words, the line, the chip, the moves the
 * person's page offers, the sentence the receptionist hears, Today's leak,
 * Reports' cohort. Pure.
 */
import { foldName, needsConsultation, type ConsultRules } from "./availability";
import { clockDate } from "./clock";
import type { SchemaSet } from "./schema-sets";

export const DEAL_STAGES = ["proposed", "won", "lost", "ended"] as const;
export type DealStage = SchemaSet<"deals.stage">;
export const DEAL_PERS = ["once", "month", "year"] as const;
export type DealPer = SchemaSet<"deals.per">;
export const DEAL_SOURCES = ["person", "payment"] as const;
export type DealSource = SchemaSet<"deals.source">;

/** The word a stage wears; "Client" is a stage word, never a word for a person (docs/glossary.md). */
export const DEAL_STAGE_WORDS: Record<DealStage, string> = {
  proposed: "Proposal out",
  won: "Client",
  lost: "Passed",
  ended: "Ended",
};
export const DEAL_PER_WORDS: Record<DealPer, string> = { once: "once", month: "a month", year: "a year" };
/** The line the person's page says where no deal was ever recorded. */
export const DEAL_LINE_NONE = "No proposal yet";
/** A proposal out this long with nothing back is Today's leak. */
export const WAITING_AFTER_DAYS = 7;

const DAY_MS = 86_400_000;

export function isDealStage(s: unknown): s is DealStage {
  return typeof s === "string" && (DEAL_STAGES as readonly string[]).includes(s);
}

/** The columns the people read carries for a person (people_list, 00154): the newest open or current deal, else the newest of any. */

/**
 * The one rule for which of a person's deals the pages show: an open or
 * current one first (proposed, won), then the newest. The lateral join in
 * people_list orders the same way.
 */
export function pickCurrentDeal<T extends { stage: string; created_at: string }>(rows: readonly T[]): T | null {
  const open = (d: T) => d.stage === "proposed" || d.stage === "won";
  const sorted = [...rows].sort(
    (a, b) => Number(open(b)) - Number(open(a)) || Date.parse(b.created_at) - Date.parse(a.created_at),
  );
  return sorted[0] ?? null;
}

/** "$2,500 a month", "$999.50", "$1,200 a year"; null without an amount. */
export function amountWords(cents: number | null | undefined, per: string | null | undefined, currency = "USD"): string | null {
  if (cents === null || cents === undefined || !Number.isFinite(cents)) return null;
  const whole = cents % 100 === 0;
  const money = new Intl.NumberFormat("en-US", {
    style: "currency",
    currency: currency.toUpperCase(),
    minimumFractionDigits: whole ? 0 : 2,
    maximumFractionDigits: whole ? 0 : 2,
  }).format(cents / 100);
  const p = per && (DEAL_PERS as readonly string[]).includes(per) ? DEAL_PER_WORDS[per as DealPer] : null;
  return p && per !== "once" ? `${money} ${p}` : money;
}

/** When the stage began: the proposal's send, the answer, or the end. */
export function dealSinceMs(d: DealFacts): number | null {
  const at =
    d.stage === "proposed" ? d.proposed_at : d.stage === "ended" ? d.ended_at : (d.decided_at ?? d.proposed_at);
  const ms = at ? Date.parse(at) : NaN;
  return Number.isFinite(ms) ? ms : null;
}

/** A deal as a page says it. */
export interface DealVM {
  id: string | null;
  version: number | null;
  stage: DealStage;
  word: string;
  service: string | null;
  sinceMs: number | null;
  /** "since Sep 12"; "" when the date is unknown. */
  since: string;
  /** "Proposal out · since Sep 12", "Client · since Oct 1 · $2,500 a month": the stage and its facts, without the service. */
  said: string;
  /** The service in front of `said`, for a line that stands alone. */
  line: string;
  /** The chip beside the wires and the row's second line: "Proposal out · 6 d", "Client · Ad management"; null where the visit says more. */
  brief: string | null;
  /** Days since the proposal went, for a proposal out; null otherwise. */
  waitingDays: number | null;
  /** The client's amount in words; null for every other stage and without one. */
  amount: string | null;
}

export function toDealVM(
  d: DealFacts & { id?: string | null; version?: number | null },
  tz: string,
  nowMs: number,
): DealVM | null {
  if (!isDealStage(d.stage)) return null;
  const sinceMs = dealSinceMs(d);
  const since = sinceMs === null ? "" : `since ${clockDate(sinceMs, tz, nowMs)}`;
  const waitingDays =
    d.stage === "proposed" && sinceMs !== null ? Math.max(0, Math.floor((nowMs - sinceMs) / DAY_MS)) : null;
  const amount = d.stage === "won" ? amountWords(d.amount_cents, d.per, d.currency ?? "USD") : null;
  const word = DEAL_STAGE_WORDS[d.stage];
  const said = [word, since, amount].filter((x): x is string => !!x).join(" · ");
  const line = [d.service, said].filter((x): x is string => !!x).join(" · ");
  const brief =
    d.stage === "proposed"
      ? `${word} · ${waitingDays ?? 0} d`
      : d.stage === "won"
        ? [word, d.service].filter((x): x is string => !!x).join(" · ")
        : null;
  return {
    id: d.id ?? null,
    version: d.version ?? null,
    stage: d.stage,
    word,
    service: d.service,
    sinceMs,
    since,
    said,
    line,
    brief,
    waitingDays,
    amount,
  };
}

}

/**
 * The sentence the receptionist hears about this person's deal, beside the
 * owner's note (describeLead). One per stage; never an amount; nothing
 * without a deal. Channel-neutral: "hand over" is what both do.
 */
export function dealSentence(d: DealFacts | null | undefined, nowMs: number, tz = "UTC"): string | null {
  if (!d || !isDealStage(d.stage)) return null;
  const svc = d.service ? ` (${d.service})` : "";
  const sinceMs = dealSinceMs(d);
  const on = sinceMs === null ? "" : ` on ${clockDate(sinceMs, tz, nowMs)}`;
  const since = sinceMs === null ? "" : `, since ${clockDate(sinceMs, tz, nowMs)}`;
  switch (d.stage) {
    case "won":
      return `They are a client${svc}${since}. Offer them the service itself, not a consultation. Anything about their engagement or what it costs goes to a person: say someone will follow up, and hand over.`;
    case "proposed":
      return `A proposal${svc} went out to them${on} and is waiting on their answer. If they ask about it, say the person who sent it will follow up, and hand over. Never discuss its price.`;
    case "lost":
      return `They passed on a proposal${svc}${on}. Do not bring it up; if they ask again, hand over to a person.`;
    case "ended":
      return `A former client${svc}: the engagement ended${on}. Treat them as any customer.`;
  }
}

/** A calendar title that is a consultation: it says so, or it names a consult-first service. The fold is availability's. */
export function isConsultationTitle(
  title: string | null | undefined,
  services: readonly { name: string }[] | undefined,
  rules: ConsultRules | null | undefined,
): boolean {
  const t = foldName(String(title ?? "").trim());
  if (!t) return false;
  if (t.includes("consult")) return true;
  return (services ?? []).some((s) => {
    const n = foldName(String(s.name ?? "").trim());
    return !!n && t.includes(n) && needsConsultation(s.name, rules);
  });
}

/** Whether the workspace's profile or its records make deals a thing here: the person's page draws its section, People its lists. */
export function dealsAreAThing(consultFirst: readonly string[] | undefined, anyDeal: boolean): boolean {
  return anyDeal || (Array.isArray(consultFirst) && consultFirst.length > 0);
}

/** Today's leak: proposals out past a week with nothing back since they went. `askedMs` is when the person last wrote or called. */
export function proposalsWaiting<T extends { deal: DealVM | null; askedMs: number | null }>(
  rows: readonly T[],
  nowMs: number,
): T[] {
  return rows.filter((r) => {
    const d = r.deal;
    if (!d || d.stage !== "proposed" || d.sinceMs === null) return false;
    if (nowMs - d.sinceMs < WAITING_AFTER_DAYS * DAY_MS) return false;
    return r.askedMs === null || r.askedMs < d.sinceMs;
  });
}

export interface DealReportVM {
  present: boolean;

  /** "3 became clients · 1 passed · 1 still waiting"; "" when none went out. */
  parts: string;
  /** "4 clients now · $7,500 a month." */

}

const n = (count: number, one: string, many: string) => `${count} ${count === 1 ? one : many}`;

export function toDealReportVM(dto: DealReportDto | null | undefined, rangeLabel: string): DealReportVM {
  if (!dto || !dto.any) return { present: false, headline: "", parts: "", stock: "" };
  const headline =
    dto.sent === 0
      ? `No proposals went out in the last ${rangeLabel}.`
      : `${n(dto.sent, "proposal", "proposals")} went out in the last ${rangeLabel}.`;
  const parts =
    dto.sent === 0
      ? ""
      : [`${n(dto.won, "became a client", "became clients")}`, `${dto.lost} passed`, `${dto.waiting} still waiting`].join(" · ");
  const monthly = dto.monthly_cents > 0 ? amountWords(dto.monthly_cents, "month") : null;
  const stock =
    dto.clients === 0 ? "No clients right now." : `${n(dto.clients, "client", "clients")} now${monthly ? ` · ${monthly}` : ""}.`;
  return { present: true, headline, parts, stock };
}
```

```ts
import { write } from "@/server/route";
import { contactScope, recordDecision } from "@/server/verbs";

const Body = z
  .object({
    stage: z.enum(DEAL_STAGES),
    /** Absent: a new engagement, which starts proposed. Present: the row the page saw, with the version it saw. */
    deal_id: z.string().uuid().optional(),
    version: z.number().int().min(1).optional(),
    service: z.string().trim().min(1).max(80).optional(),
    /** An ISO instant; absent means now. */
    when: z
      .string()
      .refine((s) => Number.isFinite(Date.parse(s)), "when must be an ISO instant")
      .optional(),
    amount_cents: z.number().int().min(0).max(1_000_000_000).optional(),
    per: z.enum(DEAL_PERS).optional(),
    note: z.string().trim().max(200).optional(),
    /** Evidence, the consent's shape: the inbound message they said it in, or a note saying where it was signed. */
    message_id: z.string().uuid().optional(),
    form_note: z.string().trim().min(1).max(200).optional(),
  })
  .strict();

/**
 * POST /api/v1/contacts/:id/deal — record a deal on a person's word (0004).
 *
 * One route for a new engagement (no deal_id: it starts proposed) and for a
 * move (deal_id and the version the page saw). The SQL door decides and
 * writes the stage's event; this records the decision, as the consent route
 * does. The receptionist never calls it.
 */
export const POST = write({
  scope: contactScope,
  role: "operator",
  rate: "person_edit",
  input: Body,
  handle: async ({ ctx, row: contact, input }) => {
    const evidence = input.message_id ? { message_id: input.message_id } : input.form_note ? { form: input.form_note } : null;
    const { data, error } = await ctx.supabase.rpc("deal_record", {
      p_contact_id: contact.id,
      p_stage: input.stage,
      ...(input.deal_id ? { p_deal_id: input.deal_id } : {}),
      ...(input.version !== undefined ? { p_version: input.version } : {}),
      ...(input.service ? { p_service: input.service } : {}),
      ...(input.when ? { p_when: new Date(input.when).toISOString() } : {}),
      ...(input.amount_cents !== undefined ? { p_amount_cents: input.amount_cents } : {}),
      ...(input.per ? { p_per: input.per } : {}),
      ...(input.note ? { p_note: input.note } : {}),
      ...(evidence ? { p_evidence: evidence } : {}),
    });
    if (error) throw new AppError("validation", error.message);
    const r = (data ?? {}) as { error?: string; deal?: DealDto; from?: string | null };
    if (r.error || !r.deal) throw new AppError("validation", DEAL_REFUSALS[r.error ?? ""] ?? "Could not record this.");
    const decision_id = await recordDecision(ctx, contact.tenant_id, "deal", r.deal.id, "record_deal", {
      contact_id: contact.id,
      stage: input.stage,
      from: r.from ?? null,
      service: r.deal.service ?? null,
    });
    return { deal: r.deal, from: r.from ?? null, decision_id };
  },
});
```

```ts
import type { RouteContext } from "@/server/route";
import type { DealReportDto } from "@chanlytics/contracts";

/**
 * Reports' Deals numbers (0004): one cohort — the proposals sent in the period
 * and what became of them — and the stock, clients now with their monthly
 * total. Counts over columns under the member's own RLS; null on an older
 * database, where the section is not drawn.
 */
export async function dealReport(ctx: RouteContext, tenantId: string, days: number, now = new Date()): Promise<DealReportDto | null> {
  const { data, error } = await ctx.supabase
    .from("deals")
    .select("stage, proposed_at, amount_cents, per")
    .eq("tenant_id", tenantId);
  if (error || !data) return null;
  const since = now.getTime() - days * 86_400_000;
  const cohort = data.filter((d) => Date.parse(d.proposed_at) >= since);
  const running = data.filter((d) => d.stage === "won");
  const monthly = running.reduce((s, d) => {
    if (d.amount_cents === null) return s;
    if (d.per === "month") return s + d.amount_cents;
    if (d.per === "year") return s + Math.round(d.amount_cents / 12);
    return s;
  }, 0);
  return {
    any: data.length > 0,
    sent: cohort.length,
    won: cohort.filter((d) => d.stage === "won" || d.stage === "ended").length,
    lost: cohort.filter((d) => d.stage === "lost").length,
    waiting: cohort.filter((d) => d.stage === "proposed").length,
    clients: running.length,
    monthly_cents: monthly,
  };
}
```
