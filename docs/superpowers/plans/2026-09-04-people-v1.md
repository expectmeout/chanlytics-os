# People v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Flip the People surface (`#/clients`) from mockup seeds to real data: a list of everyone who has written to or phoned the business, and a timeline-first profile per person, with nothing rendered that the database cannot back.

**Architecture:** One SECURITY INVOKER SQL function (`people_list`) computes the per-person facts under RLS; two `/api/v1/contacts` routes expose them through `withRoute` + `memberContext`; pure view-model code in `packages/contracts/src/people.ts` derives the six states and the profile; a `peopleOverride` on the SurfaceData seam feeds `window.__PEOPLE`; the existing mockup components branch to `*Real` variants that reuse the same markup and CSS.

**Tech Stack:** Postgres (Supabase, RLS), Next.js 15 route handlers, zod-free TS view models, node:test via tsx, Playwright.

Spec: `docs/superpowers/specs/2026-09-04-people-v1-design.md`.

### Task 1: The facts, in SQL

**Files:** Create `supabase/migrations/00028_people_list.sql`

- [ ] Step 1: Write the migration

```sql
-- 00028 People: one row per person with the facts the People surface renders.
--
-- SECURITY INVOKER, like metrics_summary. Every inner select runs as the
-- caller, so RLS on contacts, contact_identities, conversations, messages,
-- calls and escalations scopes the answer to the workspaces they belong to.
--
-- Event time follows the rule the metrics and the thread memory already use:
-- a message happened at channel_ts. A row imported from the Blob era with no
-- channel_ts contributes NO time (created_at is the import moment, not the
-- conversation) and marks the person as pre-existing — the evidence rule that
-- stops "2 new customers today" after a backfill.

create or replace function public.people_list(p_tenant_id uuid, p_contact_id uuid default null)
returns table (
  id                      uuid,
  display_name            text,
  wa_profile_name         text,
  phone_e164              text,
  consent                 text,
  consent_source          text,
  consent_updated_at      timestamptz,
  dnc                     boolean,
  channels                text[],
  conversation_count      integer,
  escalation_count        integer,
  needs_human             boolean,
  open_escalation_reason  text,
  open_escalation_since   timestamptz,
  latest_conversation_id  uuid,
  latest_state            text,
  latest_paused_until     timestamptz,
  latest_assignee_user_id uuid,
  latest_snooze_until     timestamptz,
  latest_wa_inbound_at    timestamptz,
  last_message_at         timestamptz,
  last_message_direction  text,
  last_message_sender     text,
  last_inbound_text       text,
  last_inbound_at         timestamptz,
  last_call_at            timestamptz,
  call_count              integer,
  call_seconds            integer,
  first_contact_at        timestamptz,
  earliest_row_at         timestamptz,
  has_backfill            boolean,
  has_chat                boolean,
  queued_reply_at         timestamptz
)
language sql
stable
set search_path = public
as $$
  with ev as (
    select m.contact_id, m.direction, m.sender, m.type, m.body, m.status, m.created_at,
           case when coalesce(m.meta->>'backfill', 'false') = 'true'
                then m.channel_ts
                else coalesce(m.channel_ts, m.created_at) end as at,
           coalesce(m.meta->>'backfill', 'false') = 'true' as backfill
      from messages m
     where m.tenant_id = p_tenant_id
       and m.contact_id is not null
  )
  select
    c.id, c.display_name, c.wa_profile_name, c.phone_e164,
    c.consent, c.consent_source, c.consent_updated_at, c.dnc,
    coalesce(ids.channels, '{}'::text[]),
    coalesce(cvs.n, 0),
    coalesce(esc.n, 0),
    coalesce(cvs.needs_human, false),
    oe.reason,
    oe.created_at,
    lc.id, lc.state, lc.paused_until, lc.assignee_user_id, lc.snooze_until, lc.last_wa_inbound_at,
    lm.at, lm.direction, lm.sender,
    li.body, li.at,
    lk.last_at,
    coalesce(lk.n, 0),
    coalesce(lk.seconds, 0),
    least(ma.first_at, lk.first_at),
    least(ma.first_row_at, lk.first_row_at),
    coalesce(ma.has_backfill, false),
    coalesce(ma.has_chat, false),
    ma.queued_at
  from contacts c
  left join lateral (
    select array_agg(distinct ci.channel order by ci.channel) as channels
      from contact_identities ci where ci.contact_id = c.id
  ) ids on true
  left join lateral (
    select count(*)::int as n, bool_or(cv.state = 'needs_human') as needs_human
      from conversations cv where cv.contact_id = c.id
  ) cvs on true
  left join lateral (
    select count(*)::int as n
      from escalations e join conversations cv on cv.id = e.conversation_id
     where cv.contact_id = c.id
  ) esc on true
  left join lateral (
    select e.reason, e.created_at
      from escalations e join conversations cv on cv.id = e.conversation_id
     where cv.contact_id = c.id and e.state = 'open'
     order by e.created_at desc
     limit 1
  ) oe on true
  left join lateral (
    select cv.id, cv.state, cv.paused_until, cv.assignee_user_id, cv.snooze_until, cv.last_wa_inbound_at
      from conversations cv
     where cv.contact_id = c.id
     order by cv.last_message_at desc nulls last, cv.created_at desc
     limit 1
  ) lc on true
  left join lateral (
    select e.at, e.direction, e.sender
      from ev e
     where e.contact_id = c.id and e.at is not null and e.type <> 'call_summary'
     order by e.at desc
     limit 1
  ) lm on true
  left join lateral (
    select e.at, e.body
      from ev e
     where e.contact_id = c.id and e.at is not null
       and e.direction = 'inbound' and e.type <> 'call_summary' and e.body is not null
     order by e.at desc
     limit 1
  ) li on true
  left join lateral (
    select min(e.at) filter (where e.type <> 'call_summary') as first_at,
           min(e.created_at) as first_row_at,
           bool_or(e.backfill) as has_backfill,
           bool_or(e.type <> 'call_summary') as has_chat,
           max(e.created_at) filter (where e.direction = 'outbound' and e.status = 'queued') as queued_at
      from ev e where e.contact_id = c.id
  ) ma on true
  left join lateral (
    select count(*)::int as n,
           (coalesce(sum(k.duration_ms), 0) / 1000)::int as seconds,
           max(k.started_at) as last_at,
           min(k.started_at) as first_at,
           min(k.created_at) as first_row_at
      from calls k where k.contact_id = c.id
  ) lk on true
  where c.tenant_id = p_tenant_id
    and c.erased_at is null
    and c.merged_into_contact_id is null
    and (p_contact_id is null or c.id = p_contact_id)
  order by greatest(lm.at, lk.last_at) desc nulls last, c.created_at desc
  limit 1000
$$;

revoke all on function public.people_list(uuid, uuid) from public, anon;
grant execute on function public.people_list(uuid, uuid) to authenticated;
```

### Task 3: People view models (TDD)

**Files:** Create `packages/contracts/src/people.ts`; modify `viewmodels.ts` (export `initialsOf`, `shortTime`; `clientId: string | null` set from the contact id in `toInboxThreadVM`, `toConversationVM`, `toCallVM`); `index.ts`; test `tooling/scripts/tests/people-vm.test.mjs`.

State rule (evaluated in order): needs_you → waiting_on_you → opted_out → new → quiet → active.

Test cases (write first, watch them fail, then implement):

1. open escalation ⇒ needs_you even when opted out
2. owned + last message inbound ⇒ waiting_on_you; owned + last message outbound ⇒ not
3. opted_out beats new
4. new requires no backfill and first contact ≤ 7d; a backfilled person with a fresh channel_ts is NOT new
5. quiet at 31 days, active at 29; no timestamps at all ⇒ quiet
6. name fallback: display_name → wa_profile_name → formatted phone; phone-only initials are the last two digits
7. first contact label: real ts ⇒ "Jul 14"; backfill with no ts ⇒ "Before Aug 27" and `estimate: true`
8. last contact label: "They wrote · 2h ago", "Receptionist replied · 3d ago", "They called · Aug 12"; call newer than message wins
9. aggregates: total, needsYou + oldest, newThisMonth excludes backfill, reachedWeek
10. smart lists: phoned_only = no chat and ≥1 call; opted_out list includes a needs_you person who opted out
11. timeline: messages, calls, escalations and decisions merge and sort by true time; call_summary rows skipped (the call row carries it); canceled sends skipped; decisions labelled "Took over" / "Handed back"
12. rightNow: escalation → "Escalated"; queued reply → "Reply queued"; owned → "Paused"; opted out → "Silent"; else "Answering"
13. openThread is null for a phone-only person
