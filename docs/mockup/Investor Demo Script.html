Chanlytics · Demo script

Investor walkthrough — the full loop in 12 minutes

Arc: ops autonomy → growth loop → the marketplace moat → business model Rule: nothing in this demo is a video — every moment is the live app's own wiring

The demo is built around scripted live moments that fire on real timers and real stores. Two are time-armed from page load — Riley (new lead) at ~0:18 and, later, the handoff at ~14s after connecting an agent — so the script choreographs your talking against them. Reload once before you start; each moment fires once per session.
