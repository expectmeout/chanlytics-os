# Plans

Dated plan documents, one per piece of work, written at the moment the work
was planned. They record intent and the decisions taken along the way; they
are not kept in step with the code afterwards, and several shipped without
their checkboxes being re-ticked. Read them for the why. For the what, read
the code, `docs/architecture.md` and `docs/system-prd.md`.

Designs that are decided and not yet built live in `docs/decisions/`, one file
each, and are kept current until they ship.

`docs/superpowers/` holds the plans and specs written with that workflow, in
the same spirit.
