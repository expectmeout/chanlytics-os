## 1. The packaging decision, and its first step

- `docs/decisions/0023-how-the-packages-ship.md`: why `packages/*/dist` is committed and inlines `@chanlytics/*`
  (Vercel's function bundler does not follow pnpm's links; the edge re-exports each dist by relative path), what it
  costs today (core's dist 1.88 MB; a contracts change rewrites four dists; two copies of `AppError` and of the
  provider breaker in one instance; Dependabot's html-to-text bump can never pass the drift guard), the three
  options (externalise `@chanlytics/*` with the edge resolving dist by path; the edge builds its own bundle from the
  sources; keep inlining and brand every shared class), the decision, and its steps, each shippable in either
  deploy order. Listed in `docs/decisions/README.md`.
- Step 1, built here: **third-party code is never inlined.** Every package declares each third-party module its
  dist imports (core and jobs gain `@supabase/supabase-js` and `html-to-text`), and each `tsup.config.ts` marks
  every non-`@chanlytics/*` bare import external. Proved by a test that reads each built dist: every bare import is
  declared, and no module from `node_modules` is bundled. The edge still resolves them (the hoisted linker; the
  built edge facades import and run under Node), core's dist shrinks (measured), and the `AppError` brand and the
  breaker tests stay green.
