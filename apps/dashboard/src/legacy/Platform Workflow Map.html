Workflow map — is every path clean?

Question: from any user action or lead interaction, is there a full frontend path on shared infra? Method: traced against the code — every chip below is a real store, event, or route

Four flows cover everything the product does: an inbound lead, an inbound decision (the interrupt spine), agent-initiated outbound, and the agent-platform loop. All four complete end-to-end on shared infra with no duplicated state. Three places are thinner than the rest — flagged in §06 with recommendations, none blocking.

06Findings

  • Clean All four flows complete with no dead ends; every platform failure state (404 card, 401 scope, push sig, quota cap, rejection) has a recovery affordance reachable from wherever it surfaces.
  • Clean Single-owner stores throughout — the rejected-listing state, for example, lives only on the listing object; bell, Tasks, Store, and Studio all derive from it.
  • Closed Live inbound-lead moment. ~18s into a session Riley Nguyen texts back after a missed call: bell push (accent, deep-links the lead), phone-source strip ticks +1, the row lands in Leads, and 9s later Qualifier's score updates the same row in place — LD_STORE.arrive() · leads:arrived {`{phase}`}, sums contract held mid-session.
  • Closed Bell pushes now cover all four flows. Added: leads:converted (flow 1 — client-record push with deep links), broadcasts:sent and outbound:approved (flow 3 — send/batch pushes); flow 2 already overlays decisions in place, flow 4 pushes review outcomes.
  • Closed Handoff & quota-cap now demonstrate themselves. ~14s after a studio-connected agent joins the fleet it emits its mapped handoff — fleet:handoff → bell push, pending Tasks row, and roster write-through (pending count, "Waiting on you" activity, recent line). The quota card now derives a consequence from the agent's declared pace (~270 cr/mo): picking a cap under pace warns inline + toasts "pauses around day N", and the projection rides into Fleet's Connection budget row.
  • By design Conversations (ledger) and Inbox (decisions) stay separate seeds linked by reference — the transcript is history, the thread is a decision; merging them would tangle the interrupt spine.
