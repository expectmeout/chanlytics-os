# @chanlytics/tooling

The scripts a person or CI runs. Nothing here ships.

## What is where

- `land.mjs`: ships a committed branch.
- `checks/`: what CI runs: the test launcher, the debt measures, lint groups, the smoke after a deploy.
- `gen/`: what writes a generated file. A generated file is regenerated by its command, never edited.
- `ops/`: scripts that act on production. Each is dry-run by default, writes a backup first and takes `--apply`.
- `evals/`, `eval-*.mjs`, `e2e-harness/`, `fixtures/`, `mobile/`, `voice/`: the evals, the browser suite's harness, and
  each domain's own scripts.
- `edge-functions.mjs` and `package-build.mjs`: the edge's bundle, and the bundle a test reads a package as.

The commands are listed in `CLAUDE.md`, under Commands.
